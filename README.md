# Solviera Teknoloji Homebrew tap

```bash
brew trust solviera-teknoloji/tap
brew install --cask solviera-teknoloji/tap/agentvera
```

Homebrew 7 asks you to trust a tap before it loads casks from it; the first line does that once.

[AgentVera](https://agentvera.dev/en/?utm_source=homebrew&utm_medium=tap&utm_campaign=install) is a desktop app for macOS, Windows and Linux that runs Claude Code, Codex, Gemini CLI, Copilot and 14 more coding agents side by side, each in a real terminal with your own CLI login.

The app updates itself after install. Issues and feature requests: [Solviera-Teknoloji/agentvera-app](https://github.com/Solviera-Teknoloji/agentvera-app/issues).
